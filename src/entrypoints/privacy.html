개인정보처리방침

시행일: 2026년 11월 9일

DropsKeeper(이하 "확장 프로그램")는 스트리밍 플랫폼 드롭스 보상 코드를 모아 Battle.net에 등록하도록 돕는 브라우저 확장 프로그램입니다. 확장 프로그램은 별도의 서버를 운영하지 않으며, 이용자의 정보를 개발자에게 전송하거나 수집하지 않습니다. 필요한 정보는 모두 이용자의 브라우저 안에만 저장됩니다.

1. 수집하는 개인정보

개발자는 어떠한 개인정보도 수집하지 않습니다. 확장 프로그램에는 회원가입, 로그인, 이용 통계, 광고, 오류 보고 기능이 없으며 외부 분석 도구도 사용하지 않습니다.

2. 브라우저에 저장하는 정보

확장 프로그램이 동작하려면 아래 정보가 필요합니다. 이 정보는 브라우저의 확장 프로그램 저장소(chrome.storage.local)에만 저장되며 기기 밖으로 나가지 않습니다.

항목 내용
보상 정보 드롭스 보상의 이름, 캠페인 이름, 이미지 주소, 획득일과 유효기간, 플랫폼 안에서 쓰는 보상 번호, 수령 여부
보상 코드 드롭스 인벤토리에서 추출한 Battle.net 등록 코드
등록 결과 코드별 등록 성공·실패 여부, 실패 이유, Battle.net 화면에 표시된 안내 문구, 처리 시각
작업 상태 진행 중인 추출·등록 작업의 대기열과 진행 위치, 목록을 마지막으로 불러온 시각
설정 코드 가리기 같은 화면 설정

확장 프로그램은 SOOP, 네이버(CHZZK), Battle.net의 아이디·비밀번호·쿠키 값을 읽거나 저장하지 않습니다. 각 사이트의 로그인은 이용자가 브라우저에서 직접 하며, 확장 프로그램은 이미 로그인된 탭 안에서 그 사이트의 기능을 호출할 뿐입니다.

3. 확장 프로그램이 접속하는 곳

확장 프로그램은 이용자가 연 아래 사이트의 탭 안에서만 동작하며, 그 사이트의 기능을 이용하기 위해 해당 사이트에 직접 요청을 보냅니다.

  • SOOP (drops.sooplive.com): 드롭스 보상 목록 조회와 코드 받기
  • CHZZK (game.naver.com, api.chzzk.naver.com): 드롭스 보상 목록 조회와 코드 받기
  • Battle.net (kr.checkout.battle.net, kr.account.battle.net): 코드 등록과 결과 확인

또한 팝업에 보상 이미지를 표시하기 위해 각 플랫폼이 제공한 이미지 주소를 불러옵니다. 이 과정에서 각 사이트가 받는 정보는 이용자가 그 사이트를 직접 방문할 때와 같으며, 각 사이트의 개인정보처리방침이 적용됩니다. 위 사이트 외의 다른 곳으로는 어떠한 정보도 보내지 않습니다.

4. 제3자 제공과 처리 위탁

개발자는 정보를 수집하지 않으므로 제3자에게 제공하거나 처리를 위탁하는 정보도 없습니다.

5. 권한을 요청하는 이유

  • 저장소(storage): 위 2항의 정보를 브라우저에 보관하기 위해 사용합니다.
  • 사이트 접근 권한: 위 3항의 사이트에서만 보상 목록을 읽고, 코드를 받고, 등록 화면을 처리하기 위해 사용합니다.

6. 보관 기간과 삭제

  • 저장된 정보는 이용자가 지우기 전까지 브라우저에 남습니다.
  • 확장 프로그램을 삭제하면 저장된 정보도 브라우저가 함께 삭제합니다.
  • 목록에서 보상을 삭제하면 화면에서 사라집니다. 다만 목록을 다시 불러왔을 때 되살아나지 않도록 해당 보상에 "삭제함" 표시는 브라우저에 남겨 둡니다.
  • 유효기간이 지난 보상은 목록, 대기열, 통계에 표시하지 않습니다.

7. 이용자의 권리

모든 정보가 이용자의 브라우저에만 있으므로 이용자는 언제든지 확장 프로그램을 삭제하거나 브라우저의 확장 프로그램 데이터를 지워 정보를 직접 삭제할 수 있습니다. 개발자는 이용자의 정보를 보유하지 않아 별도로 열람·정정·삭제를 처리할 정보가 없습니다.

8. 아동의 개인정보

확장 프로그램은 누구의 개인정보도 수집하지 않으며, 만 14세 미만 아동의 정보 역시 수집하지 않습니다.

9. 방침의 변경

이 방침은 법령이나 확장 프로그램의 기능이 바뀔 때 수정될 수 있습니다. 정보를 다루는 방식이 바뀌는 경우 새 버전을 배포하기 전에 이 페이지에 먼저 알리고, 시행일을 함께 고칩니다.

10. 문의

개인정보 처리에 관한 문의는 Chrome 웹 스토어의 DropsKeeper 지원 페이지로 보내 주세요.
